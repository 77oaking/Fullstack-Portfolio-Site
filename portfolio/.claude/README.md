# claude-config

This folder is staged here because the scaffolder couldn't write directly to `.claude/` in this Cowork session. The `setup.ps1` / `setup.sh` script copies its contents into `.claude/` at the repo root on first run.

After setup, this folder can be removed.

What's inside:

- `commands/` — slash commands available in Claude Code (`/new-resource`, `/new-theme`, `/review`).
- `mcp.json` — placeholder for MCP server config (GitHub, MongoDB).
